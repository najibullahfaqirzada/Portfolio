# Najibullah Faqirzada — Web Development Portfolio

A responsive personal portfolio created with HTML5 and CSS3 for The Tech Academy HTML and CSS final portfolio assignment. It introduces me, highlights course projects, links to my GitHub profile, and provides a simple contact route.

## Website sections

- **Home:** introductory message, animated background typing video, and a link to projects.
- **About:** a short personal introduction, coding-themed visual, and a small code-window design.
- **Projects:** links to Academy Cinemas, Simple Recipes, and The Pet Shop Website.
- **GitHub:** links to my public GitHub profile and course repository.
- **Contact:** a clear way to connect through GitHub. The page does not use a back-end contact form.

## Design and accessibility

- Custom palette: mint green, deep green, ruby red, and black.
- Responsive layouts for desktop and mobile screens.
- Navigation links, visible hover/focus states, semantic HTML sections, descriptive image alternative text, and reduced-motion support.
- The hero video is muted, loops, and plays inline.

## Run locally

Open `index.html` in a modern browser. Keep the `stylesheet` and `images` folders in their current locations so the local CSS, video, and GitHub image paths continue to work. An internet connection is needed for the Pexels photo.

## Publish with GitHub Pages

1. Upload the contents of this `Portfolio` folder to the root of the public `Portfolio` GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Wait for GitHub Pages to publish the site and open the URL shown in the Pages settings.
